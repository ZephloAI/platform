What to look for. Click Current time or Tip on $48 — these force a tool call. You should see: stream_start → many stream_delta frames (lead-in growing) → stream_end → status (tool label) → another stream_start → more deltas (final answer growing) → stream_end → response (metadata finalizer carrying the matching stream_id). The Long answer prompt usually skips the tool call, so you get a single stream that's enriched with sources by the response frame at the end.
