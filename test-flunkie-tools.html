Registered Tools

These tools are sent to the agent via the init message on WebSocket connect.

get_page_title

Returns the current page title

no params

add_to_cart

Add an item to the shopping cart

item: string (required), quantity: int

get_user_location

Returns the user's current timezone and language

no params

search_products

Search products on the current page

query: string (required), max_results: int

search_flights

Declarative form — auto-submit

origin, destination, date, passengers, cabin, direct

find_house

Declarative form — fill-only

location, type, price, beds, baths, amenities

Declarative Form: Flight Search

This form is auto-registered as a tool via flunkie-tool-name. Uses flunkie-auto-submit so the agent fills AND submits.

Declarative Form: House Search

Fill-only mode (no flunkie-auto-submit). The agent populates the fields and the user reviews before submitting.

Try these prompts to trigger tool calls: • "What page am I on?" → triggers get_page_title
• "Add 3 wireless headphones to my cart" → triggers add_to_cart
• "What timezone am I in?" → triggers get_user_location
• "Search for laptops" → triggers search_products
• "Find me a flight from JFK to LHR on March 15" → triggers search_flights (auto-submit)
• "Find a 3 bedroom house in San Francisco under $800k" → triggers find_house (fill-only)
