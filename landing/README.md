# Zephlo Landing (Go)

The marketing site as a single Go binary: `net/http` + `html/template` +
[htmx](https://htmx.org) for the two lead forms + Tailwind CSS built at
compile time. Templates and static assets are embedded, so the production
artifact is one self-contained executable.

This is the Go port of `../landing` (Next.js) — same design tokens, copy,
and pages.

## Layout

```
main.go                     server, routes, form handlers, sitemap/robots
templates/base.html         layout: <head>, meta/OG/JSON-LD, navbar, footer
templates/partials/         navbar, footer, forms (+ htmx success states)
templates/pages/            home, customer-success, security
assets/site.css             Tailwind input (design tokens ported from Next.js)
static/css/site.css         generated by `make css` — do not edit
static/js/site.js           theme toggle, reveals, hero demo, feeds (~150 lines)
static/js/htmx.min.js       vendored htmx 2.0.4
```

## Develop

```sh
make css        # rebuild static/css/site.css (rerun after editing templates,
                # since Tailwind scans them for class names)
go run . -dev   # -dev re-reads templates from disk on every request
```

## Configuration (env)

| Variable            | Default                  | Purpose                        |
| ------------------- | ------------------------ | ------------------------------ |
| `PORT`              | `3000`                   | listen port                    |
| `SITE_URL`          | `https://zephlo.ai`      | canonical URL, sitemap         |
| `DASHBOARD_URL`     | `https://app.zephlo.ai`  | sign-in / register CTAs        |
| `DOCS_URL`          | `https://docs.zephlo.ai` | docs links                     |
| `SALES_EMAIL`       | `sales@zephlo.ai`        | talk-to-sales mailto           |
| `ZEPHLO_CHATBOT_ID` | _(unset)_                | agent UUID for the live widget on this site; empty disables the embed |
| `ZEPHLO_API_URL`    | `https://app.zephlo.ai`  | widget API host                |
| `ZEPHLO_WIDGET_SRC` | `https://unpkg.com/zephlo` | widget script URL            |

## Forms

`POST /api/pricing-lead` and `POST /api/contact` accept both htmx requests
(success partial swapped in place) and plain form posts (redirect back with
`?sent=1`, so the site works with JavaScript disabled). Leads are currently
logged via `slog` — wire a CRM/email in `main.go`'s `lead` handler when ready.

## Deploy

```sh
make docker     # multi-stage build → distroless image, ~10 MB
```
